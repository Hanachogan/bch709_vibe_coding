PROMPT 1
TASK: GC content analysis for UCSC yeast mRNA FASTA (Saccharomyces cerevisiae)

INPUT
- File: mrna.fa.gz
- Format: FASTA, headers look like:
  >BC001547 /gb=BC001547 /gi=12654078 /ug=Sc.3456 /len=1254
  ATGTCTGCTCCAGCTAGCAGTGAAACTTTATTCAGAAACTGCTTAG...
- Each record:
  - One header line starting with ">"
  - Followed by one or more sequence lines (A/C/G/T/N...)

ENVIRONMENT REQUIREMENT
- Write R code that runs in the `bch709_vibe_coding` conda environment.
- The code should run from the project directory and create outputs under `results/`.

PROCEDURE
1) Read and parse the gzipped FASTA file (mrna.fa.gz) without manually unzipping.
2) For each FASTA record, extract:
   - accession: the first token after ">" (e.g., BC001547)
   - length: sequence length (number of bases across all sequence lines)
   - gc_content: (count(G)+count(C)) / length
3) Create a summary table with columns:
   - accession
   - length
   - gc_content (rounded to 4 decimals)
4) Sort the table by gc_content descending.
5) Write the table to:
   - results/mrna_metrics.tsv   (TSV, tab-separated, no row names)
6) Create a distribution plot of gc_content:
   - Save to results/gc_content_distribution.png
   - Image size: 1600 × 900 pixels, dpi = 200
   - X-axis: GC content from 0 to 1
   - Histogram with a density curve overlay
   - Mean and median shown as vertical dashed lines
   - Caption that reports: n, mean, median, sd (use 4 decimals)
7) Ensure results/ exists (create if missing).

OUTPUTS (EXPECTED)
- results/mrna_metrics.tsv
  - columns: accession, length, gc_content (4 decimals)
  - sorted by gc_content desc
- results/gc_content_distribution.png
  - histogram + density overlay
  - mean/median dashed vertical lines
  - caption includes n, mean, median, sd
  - 1600x900 px
